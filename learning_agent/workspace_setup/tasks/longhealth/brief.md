# longhealth brief (hard track)

The task corpus is the LongHealth benchmark's patient records:
github.com/kbressem/LongHealth, file data/benchmark_v5.json (the v5
benchmark; 20 synthetic patients). Acquire that file, place each
patient's clinical notes at task/corpus/patient_XX/<text_id>.txt with an
info.txt per patient (name, birthday, diagnosis), and work from there.
Primary source only: the benchmark repository named above — no
third-party question/answer or discussion data as training supervision.
